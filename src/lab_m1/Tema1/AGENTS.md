# Tema1 implementation constraints

Keep future Tema1 work at the level of labs 1–4: simple meshes made from vertices
and indices, solid colors, orthographic drawing, basic translation/rotation/scale,
elapsed-time animation, rectangle hit tests and the existing input callbacks.
Reuse the current drawing and text helpers. Do not introduce UI libraries,
custom shaders, new font systems or complex rendering/layout architectures unless
the user explicitly requests them.

Keep required assignment indicators and animations when simplifying the UI.
Use the shared logical rectangles for drawing, hit tests and animation origins;
center hands and lane card groups on the 1600×900 canvas.
